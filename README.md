# QA RF Hub — Downloads

Firmware oficial do **QA RF Hub** da [Quero Automação](https://github.com/queroautomacao).

📦 **Versão mais recente:** [Releases](https://github.com/queroautomacao/QARFHub-Releases/releases/latest)

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `QARFHub_vX.Y.Z.zip` | firmware + interface + LEIA-ME |
| `QARFHub.ino.bin` | firmware |
| `QARFHub.ino.littlefs.bin` | interface |

## Como atualizar

Pelo computador:

1. Abra o Hub no navegador
2. **Sistema → Firmware → Atualizar Firmware**: envie `QARFHub.ino.bin`
3. Aguarde 20 segundos e envie `QARFHub.ino.littlefs.bin` do mesmo jeito
